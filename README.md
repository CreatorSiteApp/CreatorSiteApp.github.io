# SiteCreator — Production Web Portfolio

Готовая папка для развертывания портфолио в интернете (Vercel, Netlify, Cloudflare Pages, GitHub Pages).

## Содержимое папки:
- `index.html` — Оптимизированный сайт без лишних эмодзи, с ценами x10 ($150 - $450), интерактивным калькулятором, генератором брифа для Telegram, красивым векторным SVG-фавиконом и встроенной SEO-разметкой Schema.org.
- `robots.txt` — Инструкции для поисковых роботов Google, Bing, Yandex.
- `sitemap.xml` — Карта сайта для быстрой индексации в Google Search Console.

## Как запустить сайт в интернете за 1 минуту:
1. **Netlify Drop (Мгновенно без регистрации)**:
   - Открой https://app.netlify.com/drop
   - Перетащи папку `sitecreator` целиком в окно браузера.
   - Получишь рабочую публичную ссылку за 10 секунд.
2. **Vercel (Рекомендуется для постоянной работы)**:
   - Зайди на https://vercel.com
   - Нажми **Add New Project** -> выбери эту папку или подключи через GitHub.
   - Ссылка будет работать всегда с бесплатным SSL-сертификатом.
